Blade-to-blade loop sandbox

Candidate loop definition in the unwrapped s-q domain. x is streamwise s, y is circumferential q = r * delta theta. The same domain rule is used for main blades and splitters; splitters use a shorter s interval and half-pitch phase.
Construction intent: pressure and suction are normal offsets from one S-camber meanline; leading and trailing caps close the loop in the same s-q domain. This sandbox deliberately does not use the current 3D generator, so defects here indicate loop math, while defects only in the model indicate the s-q-h to 3D mapping or loft stage.
